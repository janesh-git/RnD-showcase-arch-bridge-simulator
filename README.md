# Masonry Arch Bridge — Thrust Line Simulator

**[▶ Live demo](https://rnd-showcase-arch-bridge-simulator-jdjgodutflgded4lszauqv.streamlit.app/)**

Interactive tool that plots the thrust line of a masonry arch bridge for
user-defined span, rise, block thickness and live load positions, and shows
where hinges form when the thrust line leaves the arch geometry.

## Running locally

```
pip install -r requirements.txt
streamlit run app.py
```
